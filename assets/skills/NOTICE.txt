https://esco.ec.europa.eu/en/about-esco/faq?page=1

The snapshot includes 13,939 active English skill concepts retrieved from
the official ESCO API. Only concept UUIDs and preferred labels are kept.
Translations, descriptions and alternative labels are omitted. Labels are
unchanged. Inputs offer labels compatible with the existing 64-character
field validation. Users may also save their own free-text skills.

The ESCO API software is separately licensed. No API software is bundled.
