Общий справочник навыков использует подсказки и свободный ввод. Зарегистрированный участник ищет среди всех зарегистрированных, включая управляемые Полом профили. Реализованы серверные Community create/feed/close/expiry, общая очередь Web Push и устойчивое удаление обычного/управляемого профиля с сохранением истории собеседника. Очистка включает фото незавершённых управляемых профилей после удаления создателя. Поздняя загрузка в такой префикс отклоняется. Завершённые управляемые профили сохраняют самостоятельные данные. Локальная серверная проверка прошла 20 application migrations, 17 SQL suites, 68 Deno tests и 45 concurrency gates. Все 41 затронутые функции, аргументы, ACL и настройки совпали с hosted Supabase. Оба cron имеют успешные запуски и HTTP 200. Community проверена реальной доставкой Chrome и переходом по URL уведомления. Системное нажатие остаётся отдельным критерием.

Реальные Google/Apple зависят от настроек владельца и фактической проверки сервисов. Прежняя реализация телефонного обнаружения не используется в текущем интерфейсе; её миграции и данные сохраняются без удаления. Настройка SMS-провайдера исключена из текущих зависимостей.

## P13. Community reach out — Local

Реализовано в #47/#48, клиентская приёмка открыта. [Макет](https://www.figma.com/design/8tCP0Pg2UghSOPP5bIg9Ra/UI?node-id=61818-2319).

Из пустой выдачи поиска пользователь создаёт запрос специалиста. Ленту Hiring читают все зарегистрированные участники на всех уровнях. Публикация доступна после десяти завершённых регистраций по личному приглашению. Одновременно активных запросов может быть любое количество.

Push нового запроса получают все зарегистрированные участники с действующим разрешением уведомлений, сервер проверяет текущие права.

## Технические и организационные зависимости

1. Основной продукт — устанавливаемое Flutter-приложение iOS/Android по мобильным экранам Figma; ограниченное браузерное превью и полная проверочная версия имеют отдельные назначения. Согласованные изменения реализуются по актуальным заголовкам GitHub. Оценки и даты сохраняют фактические подтверждения.
2. Supabase выбран и используется для Auth/Postgres/Storage/Realtime/Edge Functions. Web Push/VAPID подключён к существующей серверной очереди. Native push runtime и серверный transport установлены, реальная FCM/APNs доставка ждёт credentials/signing и проверки на телефонах.
3. Настройка и реальный вход Google/Apple, клиентские материалы Terms/Privacy и передача владельцу имеют собственные фактические результаты. SMS-подтверждение исключено из объёма.
4. Глобальный поиск, общий справочник, уровни2/10, удаление, Admin и Community реализованы в текущей очереди. Клиентская приёмка остаётся открытой. Представление общего знакомого P14 и расширенный P16 имеют отдельные задачи.
5. Проверки выполняются локально, GitHub Actions требует отдельного разрешения. Секреты и приватные материалы хранятся вне исходников и публичных артефактов.
